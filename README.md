# Groove prototype

Groove is a local event discovery concept, piloting in Makhado Local Municipality, Limpopo. The visual identity uses a bright blue inspired by classic Twitter blue (#1DA1F2), with light blue accents.

## Run it
Open `index.html` in a browser. No installation is needed for the interface itself. Internet is needed for external map links.

## Included
- Category filters and search
- Poster-style event artwork and event detail view
- Google Maps directions handoff
- Review interaction using in-memory demo data
- Organizer submission placeholder
- Mobile-responsive layout

## Important limitations
- All listings are fictional sample data; none should be treated as confirmed events.
- Poster art is generated with CSS for prototype purposes, not official promotional posters.
- The map on the landing page is illustrative. Directions use sample venue text and must be replaced with verified addresses or coordinates.
- Reviews are demo-only, not saved to a database, and are not verified attendee reviews.
- The organizer form and admin moderation are not implemented yet.
- This is a prototype, not a production-ready application.

## Next development milestone
Move event data into a database, add verified coordinates, implement event submission and admin moderation, and add authentication and persistent review storage.
